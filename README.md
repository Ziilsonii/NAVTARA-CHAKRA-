# NAVTARA-CHAKRA-# Navtara Chakra

A single-file, self-contained web app for the Navtara (Nine Tara) cycle of Vedic astrology.

**Live app:** enable GitHub Pages on this repo (see below) and it will serve at
`https://<your-username>.github.io/navtara-chakra/`

## Features
- Choose any of the 27 nakshatras as your Janma Nakshatra
- Moon-position calculator (date/time → current nakshatra, pada, and Tara)
- Predictive table for all 9 Taras
- Remedial table with traditional remedies per Tara
- Deity, animal, tree, and direction for every nakshatra, grouped by Tara

## Deploying with GitHub Pages
1. Push this repo to GitHub (see commands below).
2. In the repo, go to **Settings → Pages**.
3. Under "Build and deployment", set **Source** to `Deploy from a branch`.
4. Set **Branch** to `main` and folder to `/ (root)`, then **Save**.
5. GitHub will publish it at `https://<your-username>.github.io/navtara-chakra/` within a minute or two.

Everything is in a single `index.html` file — no build step, no dependencies.
